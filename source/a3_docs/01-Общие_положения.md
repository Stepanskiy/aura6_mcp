# Общие положения

> **Описание:** Вводная глава документации системы АУРА 3. Описывает назначение системы — полный цикл финансового учёта рекламного агентства на платформе 1С:Предприятие 8.2. Содержит контактную информацию для обращений по вопросам работы с системой.

---

Финансовая система АУРА 3 (Система) разработана на платформе 1С:Предприятие 8.2 и предназначена для полного цикла финансового учета рекламного агентства.

По всем возникающим вопросам по работе с данной финансовой системой следует обращаться к Администратору Системы (администратор назначается директором компании).
