# Описание Главного меню

> **Описание:** Обзор структуры Главного меню системы для интерфейса финансового менеджера. Описывает все доступные пункты меню: Файл, Справочники, Журналы, Операции, Отчеты и Подписи — с указанием назначения каждого раздела. Состав меню может отличаться в зависимости от роли пользователя.

Все доступные операции находятся в Главном меню Системы. Структура и конкретные пункты меню могут отличаться у разных пользователей, в зависимости от их функциональных обязанностей.

Основные пункты Главного меню:

| --- | --- |

| - Кадровые | Группа кадровых справочников. |
| - Должности | Справочник должностей компании. |

| - Подразделения | Справочник подразделений компании. |

| - Валюты | Перечень валют, в разрезе которых ведется учет в Системе. В этом справочнике также можно посмотреть и изменить курсы валют, однако не рекомендуется делать это вручную. Для изменения курсов валют существует специальный документ: «Изменение курсов валют». При проведении вновь созданного или отредактированного документа «Изменение курсов валют» автоматически рассчитываются неоперационные курсовые разницы, возникающие при изменении курсов валют. |
| - Счета | Перечень денежных счетов (расчетных счетов и касс) |

| - Проектные справочники | Группа справочников, используемых для ведения проектов компании. |
| - Направления проектов | Перечень направлений видов услуг, предоставляемых компанией клиентам по проектной деятельности. |
| - Виды проектных работ | Перечень видов услуг, предоставляемых компанией клиентам по проектной деятельности. |
| - Распределение медиаразницы | Перечень агентств с соответствующими процентными соотношениями при распределении медиаразницы. |
| - Рекламные кампании | Перечень рекламных компаний, по которым велась, ведется или предполагается проектная деятельность. |
| - Ответственные по проектным работам | Перечень сотрудников, которых возможно назначить ответственными по проектам. |
| - Бренды | Перечень брендов, по которым велась, ведется или предполагается проектная деятельность. |
| - Сейлзхаузы | Справочник сейлзхаузов |
| - Внутренние договора | Перечень внутренних договоров |
| - Типы носителей | Перечень типов рекламных носителей. |
| - Бюджетирование |  |
| - Редактирование ЦФО | Редактирования справочника шаблонов бюджетов ОХР |
| - Задачи | Перечень задач созданных системой. В обычном режиме редактирование и просмотр задач производится в консоли задач |
| - Типы задач | Перечень всех возможных типов задач, с их описание и стандартными тексами, которые выводятся при просмотре задачи. Так же в этом справочнике определяется операция, которая вызывается прямо из окна просмотра задач |
