# Константы

> **Описание:** Справочник системных констант АУРА 3. Описывает параметры, задаваемые единожды при настройке системы: основная валюта учёта, фирма по умолчанию, ставки налогов (НДС, НнР), даты запрета редактирования, настройки документооборота и другие ключевые системные параметры.

---

# Константы ???

| **Наименование** | **Описание** |
| --- | --- |
| Фирма по умолчанию | Фирма, которая устанавливается в документах и отчетах по-умолчанию |
| Гривна как валюта | Служебная константа для упрощенного доступа к национальной валюте |
| Основная валюта | Базовая валюта учета. Весь учет в системе ведется в пересчете в эту валюту. Курсы валют и курсовая разница рассчитывается по отношению к этой валюте. |
| Дата запрета редактирования для документов | Данная константа позволяет закрывать период учета от изменения. Никто не может провести документы, влияющие на финансовые отчеты датой меньшей или равной данной дате |
| Затрата на которую списывается амортизация | Элемент справочника «Виды затрат» на который списываются затраты по амортизации ОС и НМА |
| Вид затраты связанный с оплатой труда | Элемент справочника «Виды затрат» на который списываются затраты на оплату труда (оклад) |
| Основная валюта покупки ОС | Основная валюта покупки ОС или НМА |
| Доходы по курсовой разнице | Элемент справочника «Виды доходов», на который начисляются доходы по неоперационной курсовой разнице |
| Расходы по курсовой разнице | Элемент справочника «Виды затрат», на который начисляются затраты по неоперационной курсовой разнице |
| НациональнаяВалюта | Национальная валюта |
| Доход по комиссии по финансовым операциям | Элемент справочника «Виды доходов», на который начисляются доходы по комиссиям по финансовым операциям |
| Доход по курсовой разнице по финансовым операциям | Элемент справочника «Виды доходов», на который начисляются доходы по операционной курсовой разнице |
| Расход по комиссии по финансовым операциям | Элемент справочника «Виды затрат», на который начисляются затраты по комиссиям по финансовым операциям |
| Расход по курсовой разнице по финансовым операциям | Элемент справочника «Виды затрат», на который начисляются затраты по операционной курсовой разнице |
| Отладка | Флаг режима отладки:<br><br>Если = 1, то включается режим отладки, который позволяет обходить некоторые ограничения регламента документооборота.<br><br>Внимание! Не устанавливать это значение без консультации с разработчиком. |
| Количество дней за которое выставляются формы на подпись | Количество дней за которые система начинает предупреждать ответственного о необходимости начала процесса подписания Ф3 |
| Создавать задачи при старте системы? | Если установлен «ДА», при старте система будет анализировать все просрочки по документообороту, оплатам и закрытию забот и выводить информацию об этих просрочках в консоли задач. |
| Отключить систему создания задач по событию? | Если установлено «Да», система не будет создавать задачи по событиям. |
| Группа АХ затрат | Код группы административно-хозяйственных затрат в справочнике «Виды затрат» |
| Вид дохода по продаже необоротных активов | Элемент справочника «Виды доходов», на который начисляются доходы, возникающие при продаже ОС |
| Вид затрат по продаже необоротных активов | Элемент справочника «Виды затрат», на который начисляются затраты, возникающие при продаже ОС |
| Генеральный директор | Генеральный директор группы компаний (холдинга) |
| Управляющая компания | Управляющая компания группы компаний (холдинга) |
| Количество дней, за которое нужно предупреждать о наступлении дедлайна | Количество дней за которое система начинает предупреждать ответственного по брифу о необходимости его закрытия |
| Дата закрытия таймшитов | Запрет редактирования табелей учета рабочего времени датой меньшей или равной этой даты |
| Доход по ошибкам округления | Элемент справочника «Виды доходов», на который начисляются доходы по ошибкам округления |
| Затраты по ошибкам округления | Элемент справочника «Виды затрат», на который начисляются затраты по ошибкам округления |
| Утверждать проекты только с полностью заполненными формами | Если стоит «Да», то система не позволит перевести проект в работу, если у него не будут полностью заполнены графики платежей (т.е. все Ф2 и Ф3) |
| Ставка НДС | Ставка НДС в процентах |
| Ставка НнР | Ставка налога на рекламу в процентах |
| Финансовый менеджер может редактировать проект без утверждения | Если стоит «Да», то финансовый менеджер и финансовый директор могут редактировать и сохранять проекты без их переутверждения. |
| КБ: Вид платежа (приход) для конвертации из клиент-банка | Элемент справочника «Виды платежей», который устанавливается по-умолчанию для входящих платежей при импорте из системы «клиент-банк» |
| КБ: Вид платежа (расход) для конвертации из клиент-банка | Элемент справочника «Виды платежей», который устанавливается по-умолчанию для исходящих платежей при импорте из системы «клиент-банк» |
| КБ: Код группы новых контрагентов | Код группы справочника «Клиенты», в которую записываются все новые контрагенты при импорте из системы «клиент-банк» |
| Контролировать валюту по формам | Если = «Да», система контролирует совпадение валюты формы и валюты платежа. |
| Вид затраты по начислению премий | Элемент справочника «Виды затрат», на который начисляются затраты по премиям и бонусам |
| Валюта учета зарплаты | Валюта, в которой начисляется заработная плата |
| Контрагент расчета с бюджетом | Контрагент, с которым производятся расчеты с бюджетам по начисленным налогам и сборам. |
| Дата на которую актуален расчет НКР | Дата актуальности расчета неоперационной курсовой разницы. Данная дата используется в механизме контроля актуальности НКР. |
| Финансовый директор не сообщает о закрытии работы в проекте ответственным | Если = «Да», то при закрытии работы финансовым директором, система не информирует ответственных по работе. |
| Дата запрета редактирования всем, кроме финансового директора | Дата запрета редактирования документов, влияющих на финансовую отчетность, всем сотрудникам, кроме финансового директора |
