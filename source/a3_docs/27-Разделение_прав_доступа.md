## Описание интерфейсов и прав доступа на уровне конфигуратора

| **Интерфейс** | **Права доступа** | **Назначение** | **Возможные роли** |
| --- | --- | --- | --- |
| Полный | Администратор | Административный доступ к систем. Возможно редактирование всех справочников и документов системы. Запуск групповых обработок документов и обработок интеграции системы с бухгалтерскими системами. | АД,ФМ,ФД |
| Финансы | Финансы | Доступ ко всем элементам системы (аналогично администратору). В этом интерфейсе отсутствует доступ к редактированию информации о правах пользователей. | ФД,ФМ,БГ,МД |
| Эккаунт | Эккаунт | Имеет право создавать и редактировать проекты. Имеет доступ ко всем проектным отчетам. | ЭТ,НЭО,КД, НБ, МБД |
| Директор | Директор | Доступ аналогичный доступа интерфейса «Эккаунт» . Добавлена возможность формирования регламентированных отчетов. | ДК  |
| Подрядчик | Подрядчик | Возможность редактирования затратной части проектов. Формирования проектных отчетов. | СВП, НВП |
| Сотрудник | Сотрудник | Право на создание и контроль своих форм №6 | СК  |
| Трафик | Трафик | Доступ к специальным отчетам и обработкам по контролю и управлению подсистем работы с брифами и учета рабочего времени | ТФ  |

## Описание ролей пользователей в системе

Каждому пользователю системы может быть присвоено неограниченное количество ролей.

Каждая роль может быть привязана к конкретной фирме (если в системе ведется учет по нескольким фирмам) или не привязываться к фирме, тогда эта роль будет распространяться на все фирмы группы или (холдинга)

,

**Описание ролей, использующихся в системе**

| **Наименование роли** | **Сокр.** | **Описание** |
| --- | --- | --- |
| Администратор | АД  | Имеет доступ ко всем элементам системы. |
| Директор компании | ДК  | Имеет доступ ко всем отчетам и документам системы только на просмотр |
| Медиа директор | МД  | Доступ аналогичен доступу ДК. Отличие в цепочках утверждения проектов |
| Финансовый директор | ФД  | Имеет полный доступ ко всем документам и отчетам по своей компании |
| Финансовый менеджер | ФМ  | Права аналогичны роль «Администратор» только без возможности входа в «Конфигуратор» |
| Медиа баинг директор | МБД | Доступ ко всем проектам (как доходы так и затраты)<br><br>Утверждение бюджетов проектов |
| Эккаунт-менеджер | ЭТ  | Права на создание и редактирование проектов. Формирование отчетов по своим проектам. |
| Начальник отдела по работе с клиентами | НЭО | Просмотр проектов и отчетов по проектам, в которых эккаунтами являются сотрудниками отдела, в котором он является начальником |
| Менеджер по работе с подрядчиками (внутренний подрядчик) | СВП | Имеет право выступать в качестве ответственного по затратным работам. Может редактировать графики платежей и закрытий по работам, в которых он является ответственным. Может просматривать проектные отчеты по своим работам |
| Начальник подразделения-внутреннего подрядчика | НВП | Имеет право просматривать все работы и отчет по этим работам, ответственными по которым являются сотрудники его подразделения. |
| Бухгалтер | БГ  | Доступ к функциям, которые должен выполнять бухгалтер в рамках установленного регламента |
| Генеральный директор | ГД  | Доступ аналогичен роли «ДК» |
| Директор по работе с клиентами | КД  | Доступ ко всем проектам и ко всем отчетам по проектам |
| Сотрудник компании | СК  | Доступ к созданию, редактированию Ф6 и отчетам по ним. |
| Трафик | ТФ  | Доступ к расширенным отчетам и сервисным обработкам по подсистеме работы с брифами и подсистеме учета рабочего времени |

## Порядок добавления нового пользователя в систему

| 1.  | Выяснить какие функции будет выполнять пользователь в системе |
| --- | --- |
| 2.  | Проверить введен ли сотрудник в справочник «Сотрудники» системы. Если пользователь не введен, обратится в кадровую службу, чтобы он был добавлен |
| 3.  | В конфигураторе добавить пользователя (в качестве учетной записи указать фамилию на русском, в случае наличия в базе пользователя с той же фамилией, добавить к фамилию инициалы без пробелов и точек). В качестве рабочей папки указатать «.\\users\\&lt;учетная запись&gt;». Выбрать соответствующие функциям пользователя интерфейс и права. Задать пароль (не менее 6 символов). Сохранить список пользователей. |
| 4.  | Зайти в систему под ролью администратора и в справочнике «Сотрудники» найти сотрудника, который только что был добавлен. |
| 5.  | В поле «Логин» ввести учетную запись которая была добавлена в конфигураторе на предыдущем этапе (вводить необходимо обязательно с учетом регистра). |
| 6.  | На форме редактирования информации о сотруднике нажать кнопку «Роли» и ввести необходимые роли для этого сотрудника. Сохранить элемент справочника. |
