# 4. Чутливі дані і ризики

## Чи може MCP просто запустити SPA, не пропускаючи дані через модель?

Так, це штатний режим MCP Apps. Є три рівні ізоляції:

| Рівень | Куди йдуть дані | Що бачить модель |
|---|---|---|
| Звичайний tool | У контекст моделі | Все |
| Tool з `_meta.ui.visibility: ["app"]` | Сервер Аури → хост (Claude/ChatGPT) → iframe. У контекст моделі **не потрапляє** | Тільки «консоль зарплат відкрита» |
| Прямий `fetch` з iframe через `_meta.ui.csp.connectDomains` | Браузер ↔ сервер Аури напряму. **Повз інфраструктуру провайдера** | Нічого |

Для зарплати потрібен третій рівень. Другий прибирає дані з контексту моделі, але вони все одно транзитом проходять через сервери Anthropic/OpenAI: саме хост релеїть виклики до remote MCP. Третій — не проходять взагалі.

### Відкрите питання: автентифікація iframe

OAuth-токен MCP належить хосту, в iframe він не передається. Робочий варіант, який потрібно перевірити в прототипі:

1. Tool `open_salary_console` повертає в `_meta` (не видно моделі) одноразовий короткоживучий тікет.
2. SPA обмінює тікет напряму на сесію з Аурою.

Друге питання — чи CSP ChatGPT і Claude однаково дозволяють `connectDomains` на домен Аури. В Claude це задокументовано, у ChatGPT правила віджетів відрізняються.

### Висновок для архітектури

Модулі з чутливими даними (зарплата, кадри, дивіденди) проєктуються як SPA, які MCP лише запускає. Чат там працює навігатором, а не оператором даних. Для проєктів, Ф2/Ф3, платежів дані можуть іти через модель — це і дає основну користь.

Якщо в якомусь клієнті прямий `fetch` не запрацює — план Б: власний агент на своїй інфраструктурі (див. [05-тенденції-mcp-і-альтернативи.md](05-тенденції-mcp-і-альтернативи.md)).

## Інші ризики

- **Масове введення даних.** Банківські виписки, бюджети на сотні рядків, табелі всього персоналу через чат не вводяться. Без MCP Apps або SPA тут не обійтись.
- **Дані йдуть до LLM-провайдера.** Потрібні enterprise-плани без навчання на ваших даних і приховування полів на сервері.
- **Prompt injection через самі дані.** Наприклад, «назва контрагента» зі схованими інструкціями для моделі. Захист — серверні перевірки: модель не може зробити нічого, чого не дозволено користувачу.
- **Вартість.** Ліцензія Claude Team або ChatGPT Business на кожного користувача плюс ліміти. Порівняти з поточними ліцензіями 1С.
- **Залежність від клієнтів.** MCP — відкритий стандарт, але підтримка MCP Apps у різних хостів нерівна. Кожен клієнт перевіряти окремо.
- **Детермінованість.** Регламентні звіти й закриття періоду — серверний код. LLM-звіти позначаються як ad-hoc.
