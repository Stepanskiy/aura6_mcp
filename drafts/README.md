# Аура 6 — робочі матеріали

Дослідження можливості побудувати Ауру 6: система управлінського обліку рекламних холдингів, де жоден інтерфейс не містить бізнес-логіки. Користувачі працюють через каталог SPA, чат-боти (Claude, ChatGPT тощо) або вбудований чат, а сервер Аури відповідає за дані, доступ, цілісність і бізнес-логіку.

Стан на 2026-10-31.

## Структура

```
drafts/
├─ 01–05, 07–09, 13        загальне: висновок, архітектура, стек, ризики, огляди, рішення, стенд, доступ і SPA, канали
├─ варіант-облік-з-осв/        повний облік: проводки, ОСВ, прототип на їх основі
└─ варіант-управлінський-облік/ без проводок: проєкти, медіаплани, заявки, платежі
```

Номери документів збережені з часу, коли всі вони лежали в одній папці, щоб посилання на «документ 11» лишались однозначними.
